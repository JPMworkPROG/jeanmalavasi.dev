# Jean Malavasi - Portfólio Pessoal

Portfólio pessoal desenvolvido com React, TypeScript e TanStack Router, apresentando informações sobre experiência profissional, projetos, formação acadêmica e formas de contato.

## 🚀 Tecnologias

Este projeto utiliza as seguintes tecnologias e ferramentas:

- **React 19** - Biblioteca JavaScript para construção de interfaces
- **TypeScript** - Superset do JavaScript com tipagem estática
- **TanStack Router** - Roteamento declarativo e type-safe para React
- **Tailwind CSS 4** - Framework CSS utility-first
- **Vite** - Build tool e dev server de alta performance
- **Motion** - Biblioteca de animações para React
- **Shadcn UI** - Biblioteca de componentes UI acessíveis e customizáveis
- **Lucide React** - Ícones modernos e leves
- **Vitest** - Framework de testes unitários

## 📁 Estrutura do Projeto

```
jeanmalavasi.dev/
├── public/                 # Arquivos estáticos
├── src/
│   ├── components/         # Componentes reutilizáveis
│   │   ├── header/         # Componentes de navegação
│   │   ├── ui/             # Componentes UI base (Button, Card, Badge)
│   │   └── Layout/         # Layout principal da aplicação
│   ├── lib/                # Utilitários e helpers
│   │   ├── utils.ts        # Funções utilitárias
│   │   └── pagination.ts   # Lógica de paginação
│   ├── pages/              # Páginas da aplicação
│   │   ├── Home/           # Página inicial
│   │   ├── Resume/         # Página de currículo
│   │   ├── Formation/      # Página de formação acadêmica
│   │   ├── Projects/       # Página de projetos
│   │   ├── Contact/        # Página de contato
│   │   └── NotFound/       # Página 404
│   ├── styles/             # Estilos globais
│   │   ├── globals.css     # Estilos globais e variáveis CSS
│   │   └── animations.css  # Animações customizadas
│   └── main.tsx            # Ponto de entrada da aplicação
├── Dockerfile              # Configuração Docker
├── docker-compose.yml      # Configuração Docker Compose
├── vite.config.ts          # Configuração do Vite
├── tsconfig.json           # Configuração do TypeScript
└── package.json            # Dependências e scripts
```

## 🗺️ Rotas

A aplicação possui as seguintes rotas:

- `/` - Página inicial (Home)
- `/resume` - Currículo e experiência profissional
- `/formation` - Formação acadêmica e certificações
- `/projects` - Portfólio de projetos (com paginação)
- `/contacts` - Informações de contato e formulário
- `/*` - Página 404 (qualquer rota não encontrada)
